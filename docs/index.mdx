# better-auth-is-bot

`better-auth-is-bot` is a plugin for [better-auth](https://www.npmjs.com/package/better-auth) that blocks automated requests before they reach your application routes. It reads the incoming `User-Agent` header and uses the [`isbot`](https://www.npmjs.com/package/isbot) library to decide whether the request comes from a bot. When it does, the plugin returns a `400 Bad Request` response and the request never reaches your handler.

## What the plugin does

Incoming POST and GET requests are checked against the `isbot` library, which recognises search engine crawlers (Googlebot, Bingbot), social media bots (Facebook, Twitter), monitoring tools, and many other automated user agents. Only those two HTTP methods are evaluated — other methods pass through untouched.

By default, every POST and GET route in your better-auth instance is protected. You can narrow that scope to a specific list of paths, and wildcards let you cover entire route groups at once. A custom `errorMessage` option lets you replace the default `BOT_DETECTED` string with any message that fits your application.

When a bot is blocked, the response body looks like this:

```json
{
  "message": "BOT_DETECTED",
  "error": "BAD_REQUEST"
}
```

## Minimal setup

Add `IsBot()` to the `plugins` array in your `betterAuth` configuration. No other options are required.

```typescript
import { betterAuth } from "better-auth";
import { IsBot } from "better-auth-is-bot";

const auth = betterAuth({
  // ... your other better-auth configuration
  plugins: [
    IsBot() // Protects all POST and GET routes by default
  ],
});
```

That single call protects every POST and GET route. To protect only specific paths — or to customise the error message — pass an options object:

```typescript
const auth = betterAuth({
  baseURL: "http://localhost:3000",
  database: /* your database config */,
  plugins: [
    IsBot({
      protectedEndpoints: [
        "/auth/*",
        "/admin/*",
        "/api/protected/*"
      ],
      errorMessage: "This endpoint does not allow automated requests. Please use a regular browser."
    })
  ],
});
```
