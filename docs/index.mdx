# better-auth-is-bot

`better-auth-is-bot` is a plugin for `better-auth` that blocks automated requests before they reach your application routes. It reads the incoming `User-Agent` header and uses the [`isbot`](https://www.npmjs.com/package/isbot) library to decide whether a request comes from a bot. When it does, the plugin returns a `400 Bad Request` response immediately — your auth handlers never see the request.

## What the plugin does

Only POST and GET requests are evaluated. All other HTTP methods pass through without any bot check. The `isbot` library recognises a wide range of automated user agents: search engine crawlers (Googlebot, Bingbot), social media bots (Facebook, Twitter), monitoring and testing tools, and many others.

By default, every POST and GET route in your `better-auth` instance is protected. You can narrow that scope by passing a `protectedEndpoints` array, and wildcard segments let you cover entire route groups at once. An optional `errorMessage` field replaces the default `BOT_DETECTED` string in the response body.

When a bot is blocked, the plugin returns:

```json
{
  "message": "BOT_DETECTED",
  "error": "BAD_REQUEST"
}
```

The `message` value becomes whatever you pass as `errorMessage` when that option is set.

## Add the plugin in one line

Import `IsBot` from `better-auth-is-bot` and pass it into the `plugins` array. No additional options are required to start protecting all routes:

```typescript
import { betterAuth } from "better-auth";
import { IsBot } from "better-auth-is-bot";

const auth = betterAuth({
  // ... your other better-auth configuration
  plugins: [
    IsBot() // Protects all POST and GET routes by default
  ],
});
```

To protect only specific paths and customise the error message, pass an `IsBotOptions` object:

```typescript
import { betterAuth } from "better-auth";
import { IsBot } from "better-auth-is-bot";

const auth = betterAuth({
  baseURL: "http://localhost:3000",
  database: /* your database config */,
  plugins: [
    IsBot({
      protectedEndpoints: [
        "/auth/*",
        "/admin/*",
        "/api/protected/*"
      ],
      errorMessage: "This endpoint does not allow automated requests. Please use a regular browser."
    })
  ],
});
```

When `protectedEndpoints` is set, only paths that match one of the listed patterns are checked. Paths not in the list pass through regardless of the `User-Agent`.
