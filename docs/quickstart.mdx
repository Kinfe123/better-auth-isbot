# Quickstart

Use this quickstart to move from a fresh checkout to a local run of better-auth-is-bot.

## Prerequisites
This project uses `pnpm` as its package manager.
The repository does not publish a first-run environment checklist, so begin with the package scripts and add provider keys only when a workflow asks for them.

## Run locally
1. Install dependencies with `pnpm install`.
2. Run `pnpm dev` to start or verify the project locally.

## Repository scripts
These commands are useful after the first run because they cover the main local development, build, and verification tasks.

- `test`: `vitest` runs verification for expected behavior.
- `build`: `unbuild` creates the production build or compiled package artifacts.
- `dev`: `unbuild --watch` starts the local development servers or watchers.
