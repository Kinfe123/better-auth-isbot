# Installation

This page walks you through adding `better-auth-is-bot` to an existing [better-auth](https://better-auth.com) project.

## Prerequisites

You need a working `better-auth` setup before adding this plugin. The plugin is framework-agnostic and runs anywhere `better-auth` runs.

## Install the package

Pick the package manager you already use:

```bash
npm install better-auth-is-bot
```

```bash
pnpm add better-auth-is-bot
```

```bash
yarn add better-auth-is-bot
```

## Register the plugin

Import `IsBot` and add it to the `plugins` array in your `betterAuth` config:

```ts
import { betterAuth } from "better-auth";
import { IsBot } from "better-auth-is-bot";

export const auth = betterAuth({
  // ... your existing better-auth configuration
  plugins: [
    IsBot()
  ],
});
```

That's a complete, working install. All `POST` and `GET` requests that carry a recognised bot `User-Agent` will receive a `400 Bad Request` response before reaching any handler.

## Verify it worked

Start your application and make a request with a known bot user agent:

```bash
curl -X POST http://localhost:3000/api/auth/sign-in \
  -H "User-Agent: Googlebot/2.1 (+http://www.google.com/bot.html)"
```

You should receive:

```json
{
  "message": "BOT_DETECTED",
  "error": "BAD_REQUEST"
}
```

If you see that response, the plugin is active. Head to the [Quickstart](/docs/quickstart) to explore configuration options.
